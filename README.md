# jskimece.github.io

Personal academic website of Junseob Kim, Ph.D. student in Electrical and Computer Engineering at Duke University.

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `master`.

## Where to edit

| Content | File |
| --- | --- |
| About page | `_pages/about.md` |
| News | `_news/*.md` (latest 5 on the home page, all on `/news/`) |
| Publications | `_bibliography/papers.bib` (`selected={true}` shows on the home page) |
| CV page | `_data/cv.yml` |
| CV PDF | `assets/pdf/Junseob_Kim_CV.pdf` |
| Site settings | `_config.yml` |
